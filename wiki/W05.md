# W05｜RAG 三階段的運作流程

**知識卡摘要：**使用者提問 → Retriever 從索引取得相關內容 → 把提問與內容整合成 prompt → LLM 生成有依據的回答。

## 重點
- Retrieve：根據問題查找候選片段。
- Augment：將有用片段與原始問題一起提供模型。
- Generate：生成回答，必要時附上可回查的資料來源。

## 初學者例子
問「實驗室可以飲食嗎？」→ 找出安全規範段落 → 在回應中解釋規定並顯示來源。
